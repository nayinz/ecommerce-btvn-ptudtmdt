# JavaScript Labs

Trang tổng hợp các bài thực hành JavaScript thuộc chương 08, 09 và 10. Chọn bài trên trang chủ để xem nội dung; có thể lọc theo chương, tìm kiếm bài học và quay lại danh sách để mở bài khác.

## Xem trang web

**Link test web:** [https://nayinz.github.io/ecommerce-btvn-ptudtmdt/JavaScript-Labs/](https://nayinz.github.io/ecommerce-btvn-ptudtmdt/JavaScript-Labs/)

## Chạy trên máy

1. Mở thư mục `JavaScript-Labs`.
2. Mở `index.html` bằng trình duyệt, hoặc chạy thư mục bằng một máy chủ web cục bộ như VS Code Live Server.
3. Chọn **Mở bài học** để xem bài. Dùng nút **Quay lại danh sách** hoặc nút Back của trình duyệt để trở về trang chủ.

## Nội dung

- **Lab08 — JavaScript: Language Foundations:**  gồm các walkthrough 02, 06–11 và bài tập Posts.
- **Lab09 — JavaScript: DOM and Events:**  gồm các walkthrough 01–05, 07 và 08.
- **Lab10 — JavaScript: jQuery:**  gồm các walkthrough 01 và 03–10.

Tổng cộng có **24 bài học và bài tập**. Mỗi chương có thư mục riêng chứa các trang HTML, mã JavaScript, CSS và tài nguyên đi kèm.
